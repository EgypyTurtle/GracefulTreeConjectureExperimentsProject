## k=15

在本地 PowerShell 运行启动工具，按提示输入服务器密码：

```powershell
.\tools\Start-K15.ps1 -Server YOUR_SERVER
```

工具只传输启动脚本，不覆盖搜索程序、k=14 检查点或旧日志。
使用 CPU0 上的逻辑 CPU 0–15，16 线程，独立的新检查点，默认不限时。
进入服务器后查看：`tmux attach -t eg-k15-cpu0`。

先运行一个 k，不自动递增。观察一天后，若任务长时间不完成，先分析
长尾结构与单任务规模，再决定是否停止和细分；不要频繁重启同一巨大任务。
