# Edge64 Baseline and Hard-Tail Status

Date: 2026-09-12

## Scope

This document records the edge64 baseline search for the exact five-leaf
non-spider case universe generated by the existing edge-indexed semantics. It
does not enter C9, change the frozen edge63 C8 line, or claim a result for the
full Graceful Tree Conjecture.

```text

```

The generator uses the same end-order canonicalization and naming convention

## Initial pilot

A deterministic, stratified 200,000-case pilot used the existing cascade with
explicit 0.25-second budgets per tier:

```text
Tier 0 compressed: 189,608 solved; 10,392 hard
Tier 1 diff:         1,134 additional solved
Tier 2 tension:      4,565 additional solved
bounded Tier 2 residual: 4,693 / 200,000 = 2.3465%
errors: 0
```

The residual is budget-bounded, not an exhaustive unresolved count. All
195,307 generated certificates passed independent verification.

## Hard-tail isolation

The 4,693 residual cases were frozen before further experiments.

Default-strategy survival:

```text
budget       survivors
0.5 s        1,542
1 s            741
2 s            383
5 s            146
```

Thus 4,547 cases (96.89% of the bounded residual) were budget artifacts under
the same default strategy.

On the 146 cases surviving 5 seconds, the existing `branch`, `hybrid`,
`tension`, and `diff` strategies were tested at a common 1-second budget. The
greedy tournament portfolio was:

```text
branch                         76 / 146
branch + hybrid               102 / 146
branch + hybrid + tension     116 / 146
branch + hybrid + tension
  + diff                      120 / 146
```

Deployment to the full 146-case set left 24 cases. A 30-second default-strategy
probe solved 22 of them, leaving 2 `UNRESOLVED_HIGH_BUDGET` cases.

The combined audit rechecked 9,452 solved result rows, covering 4,691 unique
cases, with zero certificate errors.

## Matched edge63 control

A deterministic 50,000-case edge63 control used the same hardware, solver
version, and `compressed -> diff -> tension` cascade with 0.25 seconds per tier:

```text
edge63 final survivors: 550 / 50,000 = 1.100%
edge64 final survivors: 4693 / 200,000 = 2.3465%
matched tail ratio: approximately 2.13x
```

This is an empirical solver-tail comparison, not a theorem.

## Structural interpretation

The remaining cases are split evenly between the two-branch and three-branch
skeletons after portfolio processing: 12 and 12. Short bridge is not enriched
in the post-portfolio set, and the exact `bridge=3` feature has no surviving
case in this sample. Central parity has nearly equal representation. The
current evidence therefore points first to late branching / solver-tail
behavior, not to a proven arithmetic obstruction.

The weighted post-portfolio planning projection is approximately 20,422 cases
over the full universe. This is a stratum-weighted planning estimate, not a
confidence interval or a closure result.

### Full production progress

`src/edge64_full_production.py` runs the frozen 10,040,677-case universe through
the nine-stage cascade, resumably. As of 2026-09-16 the first stage,
`compressed_0.5s`, stands at 3,800,064 processed cases (37.8%), with 1,291,124
solved, 2,508,940 survivors, 0 errors, and 37 verification checkpoints passing.
The later eight stages have not started.

The first attempt stalled on 2026-09-14 and wrote nothing for roughly 39 hours;
the stall, the evidence that ruled out the obvious causes, and the repairs to
the runner are recorded in
[edge64_production_stall_incident.md](edge64_production_stall_incident.md).
No certificate data was lost and the layer remains resumable.
